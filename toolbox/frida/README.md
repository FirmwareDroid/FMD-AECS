# Frida Integration for AOSP Custom Modules

Download frida for Android:
```bash
wget https://github.com/frida/frida/releases/download/17.5.2/frida-server-17.5.2-android-arm.xz
xz -d frida-server-17.5.2-android-arm.xz
chmod +x frida-server-17.5.2-android-arm
mv frida-server-17.5.2-android-arm frida-server
```
