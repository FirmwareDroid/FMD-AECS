# fsmon
Low level filesystem monitor utility for Linux, Android, iOS and macOS.
Repo: https://github.com/nowsecure/fsmon

Download fsmon for ARM64 architecture:
```
wget https://github.com/nowsecure/fsmon/releases/download/1.8.8/fsmon-and-arm64
```
Make the binary executable:
```
chmod +x fsmon-and-arm64
```
